# MaseCreator Scenario

This scenario package was generated by MASE Creator.

Run it from `mase-server` with:

```powershell
.\gradlew.bat runMase --args='--scenario "path\to\MaseCreator"'
```

The maze data is in [MaseCreator.trig](<data/MaseCreator.trig>). Active global rules are under [rules/global](rules/global). The [rules/scenario](rules/scenario) folder is currently empty and reserved for future scenario-specific rules.
